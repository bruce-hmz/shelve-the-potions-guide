# Shelve the Potions! Guide

Static-first English guide website for *Shelve the Potions!* — walkthrough, puzzle solutions (clock / color / chess), spoiler-controlled content.

```bash
npm install
npm run dev
npm run check   # tsc + next build, must pass before push
```

- Production: https://shelvethepotions.wiki (domain registered at Spaceship, deployed on Vercel)
- Routes follow the approved Phase 1 keyword matrix; every push to `main` auto-deploys production via the Vercel GitHub integration.
